# 🌍 Travel Explorer

A modern and responsive travel website that helps users discover amazing destinations, explore travel packages, and plan their dream vacations. Built using HTML, CSS, and JavaScript with a clean UI and interactive features.

---

## 📖 Overview

Travel Explorer is a front-end travel booking website designed to provide users with an engaging experience while browsing popular destinations around the world. The website includes destination filtering, travel packages, customer testimonials, FAQs, and a responsive layout for all devices.

---

## ✨ Features

- 🏠 Responsive Home Page
- 🌍 Popular Destinations Section
- 🔍 Destination Search
- 🎯 Filter Destinations
  - Price Range
  - Region
  - Trip Type
  - Sort by Rating, Price & Popularity
- 🎁 Featured Travel Packages
- ⭐ Customer Testimonials
- ❓ Interactive FAQ Section
- 📩 Contact Form
- ⬆ Scroll to Top Button
- 📱 Mobile-Friendly Navigation Menu
- 🎨 Modern User Interface
